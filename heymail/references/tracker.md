# 投递台账定稿规范

可直接打开的[空白Excel模板](../assets/templates/application-ledger.xlsx)随技能提供，含20行空白输入区、状态下拉、跟进日期提示和社科大标识。模板不含任何真实或示例投递记录。它与自动生成台账沿用同一套定稿样式；不要用空白模板覆盖已有台账。

## 功能与数据

- 这是 heymail 简历投递流程的一部分，不创建单独的模板或台账技能。
- Codex、豆包的 `tracker.root` 指向同一个本机目录；发送记录中的 Agent 以实际调用客户端为准。
- 每条JD对应一个岗位记录。同一JD的多联系人、补投或跨Agent投递合并一行；复用稳定的 `application.id`。
- 投递时间按北京时间记录，保留该岗位的首次实际提交时间，并按该列倒序排列。追加投递时间写入备注。
- 收件邮箱从实际投递事件中提取，忽略空地址，同一地址不区分大小写去重，按首次使用顺序分行显示。没有真实收件记录时留空，不猜填。旧8列表按表头迁移，保留原人工字段和稳定编号。
- 默认“已投递”仅表示SMTP接受。没有自动读信或已读状态推断。
- 测试邮件及未发送草稿不混入正式岗位记录。公司、岗位或地点无法核实时标为待确认，不猜填。

## 固定字段与布局

| 列 | 可见标题 | 更新方式 |
|---|---|---|
| A | 公司 | JD提取，保留人工修订 |
| B | 岗位 | JD提取，保留人工修订 |
| C | 工作地点 | 具体城市或“远程”；未确定时待确认 |
| D | 投递时间 | 自动记录，北京时间，最新在上 |
| E | 投递 Agent | 自动记录；同岗位可显示“Codex、豆包” |
| F | 收件邮箱 | 从实际投递记录提取；多位联系人去重后分行显示 |
| G | 当前进展 | 下拉选择，保留人工更新 |
| H | 下次跟进 | 日期，保留人工更新，到期高亮 |
| I | 备注 | 保留人工更新和追加投递说明 |

只显示以上9列。“JD来源”不再作为表格列；原始材料可留在后台归档供核对。J列 `_record_id` 隐藏并包含在结构化表中，使排序后人工字段仍对应同一个岗位。

第1—3行为品牌区，第4行为表头，第5行起为记录。冻结前4行，保留筛选。Excel中的日期使用可排序的日期值，不写成展示用字符串。刷新或排序后保留人工修订的公司、岗位、地点、进展、跟进日期和备注。

## 固定视觉规范

- 白底、校徽红 `#B81C22`、浅米白交替行、深灰正文。表头红底白字，分隔线细淡。
- 左上使用 `assets/ucass/logo-horizontal.png` 的原始横向校徽；右上使用 `assets/ucass/motto.jpg` 的“笃学 慎思 明辨 尚行”校训。保持图片原始比例，不重画或改字。
- 标题“实习投递台账”，16磅；表格用微软雅黑10磅。
- 表内、表头和品牌区均不显示用户姓名，D3留空。文件作者元数据取当前发件配置姓名，或明确指定的台账作者；作者元数据不等于可见署名。
- 常规行高22磅。仅长公司名、长岗位或长备注按换行数增加高度，不把所有行统一加高。
- 紧凑列宽：A23、B27、C10、D21、E13、F36、G11、H14、I43；J技术编号隐藏。
- 状态使用低饱和色区分；跟进日期到期高亮。保留单页台账结构，不新增封面、KPI卡片或分析图表。

共享目录存在 `.branding.json` 时沿用该样式配置；缺失时，生成器读取本技能自带 `assets/ucass/theme.json` 和原始品牌素材，继续生成定稿风格。

## 使用现有流程

1. 投递前把已核实的公司、岗位、地点和JD原文/文件写入草稿 `application`，用 `--agent` 标记实际客户端。
2. 按 heymail 原有流程展示完整邮件及全部附件，等待用户的独立“发送”。
3. 发送脚本保存回执与事件，再刷新共享Excel。台账刷新失败不影响已接受的邮件，不得因此重发。
4. 仅维护台账时，使用 `tracker-list` 查询岗位或 `tracker-sync` 刷新；这两个命令不发送邮件，也不读取邮箱凭据。
5. Excel打开造成覆盖失败时，保留事件，保存并关闭Excel后再刷新。修改台账样式时同步当前客户端与另一个已安装客户端的生成器，避免下次刷新回退。

## 不改变原投递约定

正文与简历基于真实资料；简历及课题附件仅生成字节一致的副本。主题与简历默认同名，按JD命名并剔除招聘来源平台标签。网址独立成行、前后留空行。保持预览、摘要/附件校验和防重复投递；本技能不请求已读回执。

## 桌面入口

生成台账后运行 `tracker-shortcut`，在Windows桌面创建指向原台账的快捷方式。不会把Excel复制到桌面形成过期副本；已有同目标快捷方式复用，遇到不同目标的同名文件则使用新名称。
